# Security Policy

## Reporting a vulnerability

Please report security issues to https://github.com/Ternatsu2/opsledger-sdk/security.

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/Ternatsu2/opsledger-sdk/issues

## Scope

This policy applies to the generated Terry Benjamin Jr SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the OpsLedger Read-Only SDK public API, generated by
Terry Benjamin Jr. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
